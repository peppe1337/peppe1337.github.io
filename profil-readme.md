# Projects

- **[dify-plugin-business-days](https://github.com/peppe1337/dify-plugin-business-days)** — offline business-day and public-holiday calculator for Dify. 100+ countries, no network access, no credentials. Listed in the Dify Marketplace.
- **[ki-zugangsindex](https://github.com/peppe1337/ki-zugangsindex)** — a running longitudinal measurement of which German websites block AI crawlers via `robots.txt`. Fixed panel, all raw responses included.
- **[agent-payout-ledger](https://github.com/peppe1337/agent-payout-ledger)** — what AI agent marketplaces actually pay out. Measured from public APIs, verified on-chain, raw data included.
- **[open-source-earnings-census](https://github.com/peppe1337/open-source-earnings-census)** — a repeatable census of what open source projects actually earn.

Every published number has its raw data and its code next to it, so it can be recomputed rather than believed.
